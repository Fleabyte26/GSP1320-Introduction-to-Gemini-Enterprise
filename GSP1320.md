# GSP1320 - Introduction to Gemini Enterprise

This lab has no Cloud Shell. Everything is clicks in the browser, so this file is a short click path with the prompts ready to copy.

## Known lab traps/bugs (read first)

1. Do everything in the same Incognito window, signed in as the lab student account. If Drive or Calendar opens under your personal account, the first check fails.
2. The calendar event title must match exactly: Cymbal Foods - Marketing Strategy Meeting. Start time at least one hour from now. Keep it on today's date if you can, or the "agenda today" prompt in Task 3 will find nothing.
3. Name the connectors exactly Google Drive and Google Calendar, location global.
4. Indexing takes 5-10 minutes after you connect the data stores. If answers come back empty or miss your files, wait, refresh, and ask again. This is the main reason people think the lab is broken.
5. In the web app you must click Authorize for Drive and for Calendar (Connectors, the puzzle-piece icon) before the prompts can see your data.
6. Publishing matters: click Create for the agent and Save for the skill. A draft that was never created or saved does not count.
7. Deep Research and the Notebook Studio items take several minutes. Start them and keep working; do not sit and wait.
8. The checker lags: wait 30-60 seconds and click again.

Time saver: do Task 1 and Task 2 first, then do Task 5 (Notebook) while the data stores index, then come back to Task 3 and Task 4. The checks do not depend on order.

## Task 1. Drive files and a calendar event

1. Optional look: Cloud Storage > Buckets > open the bucket named after your Project ID (not the Discovery Engine staging bucket). You should see three folders.
2. New tab > Google Drive > My Drive > Gemini Enterprise Drive Assets. You should see 4 files: MARKETING_data.csv, SALES_data.csv, customer_feedback.csv, pie_chart_customer_sentiment-png.png.
3. New tab > Google Calendar. Check the profile icon shows the student account. Dismiss any pop-ups.
4. Create > Event. Title:

```text
Cymbal Foods - Marketing Strategy Meeting
```

5. Set the start time at least one hour from now. Click Save.

Check my progress: Add content to Google Drive and Google Calendar.

## Task 2. Connect the Drive and Calendar data stores

1. Console search bar: Gemini Enterprise > open it. On Apps you should see Cymbal Foods - Gemini Enterprise, location global, with Cloud Storage connected.
2. Click Cymbal Foods - Gemini Enterprise > Connected data stores. You should see cloud-storage-ds already there.
3. Click + New data store. Search Google Drive > Add data source.
4. Authentication page: Continue. Actions: Select all actions > Continue.
5. Multi-region: global (Global). Data connector name: Google Drive. Click Create.
6. Click + New data store again. Search Google Calendar > Add data source.
7. Authentication page: Continue. Actions: Select all actions > Continue.
8. Multi-region: global (Global). Data connector name: Google Calendar. Click Create.

You should see three data stores: Cloud Storage, Google Drive, Google Calendar.

Check my progress: Connect Google Drive and Google Calendar data stores.

What you just did: the app can now search three places with one question, but it only shows each user what that user is already allowed to open.

## Task 3. Use the agents, build an agent, create a skill

Open the app: Gemini Enterprise > Overview tab > click the URL under "Your Gemini Enterprise webapp is ready". If a welcome dialog appears, click Get started.

Authorize first: in the chat box click Connectors (puzzle-piece icon) > Authorize next to Drive > Authorize next to Calendar.

Chat prompts (not scored, but they prove the connectors work). Send the first two in the same chat:

```text
Give me an update on our latest marketing data.
```

```text
What products were in the March newsletter?
```

New chat > Tools > Search company data, then:

```text
Summarize the customer sentiment pie chart.
```

New chat, then:

```text
What meetings are on my agenda today? What do I need to have prepped for them?
```

If any answer is empty or wrong, the index is not ready: wait a few minutes, refresh, ask again.

Build the agent:

1. Click the logo to go home. Navigation menu: + New agent > Chat agent.
2. In "What do you want your agent to do?", paste and press Enter:

```text
Create a Sales Assistant agent that analyzes quarterly transaction data and customer feedback.
```

3. Wait for "Your agent 'Sales Assistant' is ready". Flow tab > click the Sales Assistant node to see its name, instructions, model and data sources. If the name is not Sales Assistant, change it to that.
4. Click Create (toolbar). In the success dialog click Chat with Agent.
5. Test it:

```text
Summarize the key takeaways from our Q1 2026 sales records.
```

6. Logo > Agents. You should see Sales Assistant under Your agents.

Create the skill:

1. Navigation menu: Skills > Create skill with Gemini.
2. Paste and press Enter:

```text
Create a Cymbal Brand Voice skill that formats marketing and product summaries into Cymbal Foods' friendly, sustainability-focused executive tone and ends with a three-bullet action plan.
```

3. Wait for the fields to fill in. The name should be cymbal-brand-voice and the trigger /cymbal-brand-voice. If the name is different, change it to cymbal-brand-voice.
4. Click Save. You should see "Skill created successfully."
5. New chat. Type /cymbal-brand-voice and pick it from the Skills menu, then paste:

```text
Draft an internal announcement summarizing our Spring Cookie Promotion results.
```

You should see a "Skill used" badge and an answer that ends with three bullets.

Agent versus skill: the agent is a persona with its own data sources that you talk to. The skill is a reusable instruction you can call inside any chat.

Check my progress: Interact with your Gemini Enterprise agents.

## Task 4. Deep Research (not scored)

1. Logo > navigation menu: Deep Research. Paste:

```text
Research the latest marketing tips and tricks that food companies are using, and generate a list of actionable steps our company can take to improve our current marketing strategy.
```

2. When the research plan appears, click Start research. It takes 5-10 minutes; move on and come back.

## Task 5. Gemini Notebook

1. Navigation menu: Gemini Notebook > + Create new notebook.
2. In Add sources, under Link, click Website. Paste all three URLs, then click Insert:

```text
https://storage.googleapis.com/spls/gemini-enterprise/SALES_data.txt
https://storage.googleapis.com/spls/gemini-enterprise/customer_feedback.txt
https://storage.googleapis.com/spls/gemini-enterprise/MARKETING_data.txt
```

3. Wait until all three sources are listed and the notebook has a title and summary.
4. Ask these, one at a time:

```text
What audience did the Spring Cookie Promotion target?
```

```text
Summarize the key themes from the customer_feedback.txt regarding products that had sales figures reported in Q1 2026 in the SALES_data.txt.
```

```text
Are there any marketing campaigns in MARKETING_data.txt that correspond to products with significant customer feedback or notable sales trends from the other documents?
```

```text
What are the top 3 most frequently mentioned positive aspects in the customer_feedback.txt?
```

Notice the citations: every answer points back to the source text. The Notebook answers only from these three files, unlike the main chat, which searches all connected data.

5. In the Studio panel click Audio Overview, then Infographic, then Slide Deck. They build in the background for a few minutes. Open each one when it is ready.

Check my progress: Focused analysis with Gemini Notebook.
